# Терміни для роботи з вебсистемою

| Український термін | English equivalent | Жаргон | Пояснення в контексті курсу |
|---|---|---|---|
| Смуга версій SDK | feature band | `фіче-бенд` | Група версій .NET SDK з однаковими major, minor і цифрою сотень у patch-частині, наприклад `10.0.3xx`. Політика `latestFeature` у нашому `global.json` із нижньою межею `10.0.100` вибирає найвищу встановлену смугу та patch у сімействі `10.0`; `allowPrerelease: false` виключає попередні випуски. |
| Початковий проєкт | starter | стартер | Готовий застосунок, який ви отримуєте в архіві або репозиторії й розвиваєте в усіх ЛР |
| Початковий стан | baseline | бейзлайн | Стан starter до ваших змін. «Baseline 2-A» — назва предметної області цього потоку («Трекер інцидентів»); інших варіантів у ЛР 1 немає |
| Початкові дані | seed data | сід | Фіксований набір користувачів та інцидентів, який API записує в порожню БД |
| Відновлення стану | reset | ресет | Команда `--reset-database`: очищує навчальні таблиці й знову записує seed |
| Перевірка готовності | readiness, health check | хелсчек | Endpoint `/health`: відповідає `200`, якщо API може з’єднатися з БД |
| Кінцева точка | endpoint | ендпоінт | Пара method + URL, для якої в API зареєстровано обробник |
| Обробник | handler | хендлер | Метод або лямбда, яку викликає фреймворк для endpoint чи події в браузері |
| Метадані endpoint | metadata | — | Додаткові відомості про endpoint. `.WithName` задає його ім’я, `.Produces` описує очікувану відповідь для OpenAPI, але самі не реалізують обробник і не перевіряють його результат. Інші метадані, наприклад вимоги авторизації, можуть впливати на оброблення запиту |
| Потік списку, потік деталей | list-flow, details-flow | — | Повний шлях запиту від дії на сторінці до БД і назад для списку або для одного інциденту |
| Об’єкт передавання даних | DTO | — | Тип, що описує JSON запиту або відповіді; не збігається з entity |
| Сутність | entity | — | Клас, який EF Core відображає на таблицю БД |
| Приймач даних у DOM | DOM sink | сінк | Місце, куди JavaScript записує дані на сторінку; `textContent` — безпечний для тексту |
| Перелік дозволеного | allowlist | — | Явний список значень, які сервер приймає; решту відхиляє |
| Час життя «на запит» | scoped | — | Реєстрація в DI, за якої для кожного HTTP-запиту створюється окремий екземпляр сервісу |
| Проміжна ланка | middleware | — | Компонент конвеєра ASP.NET Core, крізь який проходить кожен запит і відповідь |
| Ідентифікатор запиту | trace identifier, `traceId` | — | Унікальне значення одного HTTP-запиту; допомагає знайти його в журналі |
| Профіль запуску | launch profile | — | Набір налаштувань у `Properties/launchSettings.json` (URL, середовище), який читає `dotnet run` |
| Позиційний record | positional record | — | Запис на зразок `record BookCard(string Title, int Pages)`: властивості задано параметрами в дужках. EF Core не завжди може «заглянути» всередину його конструктора, тому сортування й фільтр ставлять до створення такого record |
| Проєкція верхнього рівня | top-level projection | — | Останній `Select` запиту, який формує результат. Те, що створено в ньому, EF Core здебільшого вже не може перекласти в SQL для наступних операторів |
| Ідентифікатор трасування | trace-id (у заголовку `traceparent`) | — | 32 шістнадцяткові символи після `00-`, спільні для всього ланцюжка обробки запиту; наступна частина `traceId` — ідентифікатор окремого кроку (span) і на сервері буде іншою |
