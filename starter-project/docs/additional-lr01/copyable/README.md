# Готові файли WEB ЛР1

Ці файли дублюють навчальні приклади й команди методички. Вони є поруч із PDF/Word у resources/copyable/ і в такому самому каталозі розпакованого lab-01-starter.zip. До Git-repository starter їх не додають.

- LinqDemo, CategoriesDemo, DeferredDemo, ReadDemo: повні консольні проєкти. Відкрийте потрібну папку з .csproj, dotnet run; очікуваний вивід у методичці.
- EfTranslationProbe: перевірка перекладу EF Core/Npgsql без БД; README у папці пояснює межі.
- health-test.cs: навчальний метод xUnit для готового /health; вставляють у наявний IncidentEndpointTests за етапом 3, кроком 6. Це не обов’язковий новий тест і не рішення summary.
- api-fetch.js: коментований фрагмент готової функції starter для читання; повторно її не вставляйте.
- latest/: фрагменти тренування, місця вставлення й відкидання в README. Не готове рішення severity-summary.
- commands.md: блоки всіх команд із передумовами в відповідних розділах методички. Виконуйте лише потрібний блок, не весь файл.
- local-port-override.sh/.ps1: команди запуску для навчального PostgreSQL на 54330; звірте порт infra/.env, credentials тільки локальні відкриті.
- verify-details.sql/.sh/.ps1: read-only звірка details із baseline seed. shell-файли запускають з кореня starter; для infra/.env замініть env-file у копії сценарію.

PowerShell і Bash — різні термінали; не копіюйте синтаксис продовження рядків одного в інший. Консольні файли збережено UTF-8. Після власних змін перевіряйте фактичний результат, не видавайте очікування за спостереження.
